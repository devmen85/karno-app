# Woocer - اپ مدیریت محصولات ووکامرس

اپ Flutter برای مدیریت محصولات فروشگاه ووکامرس (اندروید + iOS)، بدون نیاز به بک‌اند اختصاصی —
مستقیم به REST API ووکامرس روی هاست شما وصل می‌شه.

## معماری

```
[اپ Flutter]  <-- HTTPS + REST API -->  [وردپرس + ووکامرس روی هاست اشتراکی شما]
```

هیچ سروری غیر از همون هاستی که سایت وردپرسی/ووکامرس‌تون روشه لازم نیست.

## پیش‌نیاز روی سایت ووکامرس

1. وارد وردپرس ادمین بشید.
2. مسیر: **WooCommerce > Settings > Advanced > REST API**
3. روی **Add key** بزنید، دسترسی رو **Read/Write** بذارید.
4. **Consumer Key** و **Consumer Secret** رو کپی کنید — همینا رو داخل اپ در صفحه ورود وارد می‌کنید.

> نکته امنیتی: حتماً سایت روی HTTPS باشه (گواهی SSL فعال)، چون کلیدها از طریق شبکه رد و بدل می‌شن.

## نصب و اجرا

```bash
flutter pub get
flutter run
```

```bash

```

## ساختار پروژه

```
lib/
├── main.dart                      # نقطه ورود و مسیریابی
├── models/
│   └── product.dart               # مدل محصول (متناظر با اسکیمای ووکامرس)
├── services/
│   └── woocommerce_api.dart       # لایه ارتباط با REST API
└── screens/
    ├── login_screen.dart          # ورود آدرس سایت + کلیدهای API
    ├── product_list_screen.dart   # لیست و جستجوی محصولات
    └── product_edit_screen.dart   # افزودن/ویرایش/حذف محصول
```

## قابلیت‌های فعلی
- اتصال به هر فروشگاه ووکامرس با وارد کردن آدرس سایت و کلید API (دستی یا با اسکن QR)
- لیست محصولات با تصویر، قیمت و وضعیت موجودی
- جستجوی محصول
- افزودن، ویرایش، حذف محصول
- مدیریت موجودی انبار
- **مدیریت سفارش‌ها:** لیست با فیلتر وضعیت، جزئیات سفارش، تغییر وضعیت، افزودن یادداشت
- **اعلان سفارش جدید:** بررسی دوره‌ای (polling) سفارش‌های تازه + نوتیفیکیشن محلی + صدای هشدار
- **مدیریت مشتریان:** لیست، جستجو، تعداد سفارش و مجموع خرید هر مشتری
- **دسته‌بندی و برچسب محصولات:** مشاهده، افزودن، حذف
- **اسکنر QR Code:** برای وارد کردن سریع آدرس سایت و کلیدهای API

### تنظیم صدای اعلان سفارش جدید
1. یک فایل صوتی کوتاه (مثلاً `order_alert.mp3`) در مسیر `assets/sounds/` قرار بدید.
2. در `pubspec.yaml` زیر `flutter:` این خطوط رو اضافه کنید:
   ```yaml
   flutter:
     assets:
       - assets/sounds/order_alert.mp3
   ```

### محدودیت مهم درباره اعلان‌ها
اعلان فعلی با **polling در پیش‌زمینه** (وقتی اپ بازه) کار می‌کنه، نه Push واقعی. برای اعلان لحظه‌ای حتی
وقتی اپ بسته‌ست (مثل اپ اصلی Woocer)، باید یکی از این‌ها رو اضافه کنید:
- **Webhook ووکامرس** (`WooCommerce > Settings > Advanced > Webhooks`, روی رویداد `Order created`) که
  به یک سرویس Push مثل Firebase Cloud Messaging وصل بشه، یا
  - **Task دوره‌ای پس‌زمینه** با پکیج `workmanager` (که در پروژه اضافه شده ولی نیاز به تنظیم native داره
  و در اندروید حداقل فاصله ~۱۵ دقیقه‌ست).

## قابلیت‌هایی که می‌شه بعداً اضافه کرد
- آپلود تصویر محصول از گالری/دوربین (پکیج `image_picker` از قبل اضافه شده)
- گزارش فروش و درآمد با نمودار
- مدیریت نظرات (Reviews) و کوپن‌ها
- Push notification واقعی (Firebase + Webhook)
- پشتیبانی از محصولات متغیر (Variable Products / Variations)
- چند فروشگاهی (چند اکانت هم‌زمان)

## توجه
این پروژه یک **اسکلت کاری (starter)** آماده توسعه‌ست، نه یک اپ کامل نهایی. برای انتشار در
Google Play/App Store نیاز به آیکون، اسکرین‌شات، تست کامل و رعایت سیاست‌های فروشگاه‌های اپ دارید.
